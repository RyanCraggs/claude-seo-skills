# CRO Recommendations (conditional)

Conversion-rate recommendations, included for pre-launch/redesign sites or when conversion is a stated concern. Claude assesses the client's site **live** and compares it to competitors.

## Inputs

- **Claude fetches live:** the client's homepage and key landing pages, plus competitor sites, to observe hero CTAs, audience routing, trust bars, use-case pages, lead capture, and navigation.
- Ask the user which competitors to benchmark against if not already named.

## Format

Each recommendation follows a consistent three-beat structure. Leave `[SCREENSHOT: …]` placeholders for the competitor examples.

```
**What competitors do:** [observed pattern, naming the competitor]
**Why it works:** [the conversion logic]
**[Client] can do this:** [specific, concrete action]
```

## Recurring recommendation themes

Draw from these where the live assessment supports them; don't force ones that don't apply:

- **Audience routing from the hero.** Competitors split visitors by audience (e.g., patients vs. clinicians, or consumers vs. professionals). Why: multiple audiences need different messages; one generic message serves none well. Action: add clear entry paths, each leading to a short audience-specific landing page with its own FAQs, benefits, and CTA.
- **Above-the-fold trust proof.** Competitors surface proof points and ratings in the header (BBB rating, reviews, contact details). Why: for a new/unfamiliar category, users need reassurance before they scroll. Action: add a top trust bar (e.g., a regulatory status, key differentiators, a headline safety stat) linking to the page that explains the methodology.
- **Condition / use-case pages.** Competitors organize content around conditions or use cases. Why: they create SEO entry points and help users self-qualify. Action: build education hubs around approved/carefully-framed topics; avoid treatment claims unless cleared and legally approved.
- **Lead capture beyond the footer.** Competitors use pop-ups or exit-intent modals. Why: footer sign-ups get missed; a modal is a stronger CTA and the emails fuel later marketing. Action: add a pop-up (doesn't need a discount — can be "sign up for research and news").
- **CTAs at every scroll point.** Competitors repeat "Shop/Order/Add to cart" CTAs throughout. Why: not every visitor is ready at the top; more CTAs = more conversion chances across funnel stages. Action: add CTAs beyond the nav button — including a soft mid-funnel option like "Not sure you need it? Take the quiz."

## Claim compliance

For YMYL / medical-device clients, every CRO recommendation must stay claim-compliant: no unsupported outcome claims, stick to cleared/approved language, and route product/safety questions to official resources.
